# Deep Learning Course

Public course website and teaching materials for the 16-week Deep Learning course offered by the Department of Computer Science, University of Gwadar.

## Live site

<https://hafeezug.github.io/deep-learning-course/>

## Included materials

- Updated course outline in PDF and DOCX formats
- 16 lecture decks (2 hours each)
- 16 Google Colab notebooks (3-hour weekly labs)
- Complete lab manual in PDF format

The site is intentionally static and requires no build step. GitHub Pages publishes the repository root from the `main` branch.
