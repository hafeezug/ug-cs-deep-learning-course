# CS-454: Deep Learning Course

Public course website and teaching materials for the 16-week Deep Learning course (CS-454 / CS-454L) offered by the Department of Computer Science, University of Gwadar (Batch 2024–2027, 6th Semester).

## Live Site

<https://hafeezug.github.io/ug-cs-deep-learning-course/>

## Included Materials

- Official Course Syllabus & Outline (`docs/CS454_Course Syllabus Deep Learning_Fall 2026.pdf`)
- 16 Lecture Decks in PDF format (`slides/`)
- 16 Interactive Google Colab Notebooks (`notebooks/`)
- Complete Lab Manual (`docs/Deep_Learning_Lab_Manual.pdf`)
- 5 Reference Textbooks (`books/`)
